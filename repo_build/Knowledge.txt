BASELINE
- Total sign-ins analyzed: 1,096
- Flagged by naive "unmanaged device" rule: 1,070 (97.6%)
- Auto-dismissed after device-history check: 1,066 (99.6% of flagged)
- Escalated as genuinely first-seen devices: 4 (0.4% of flagged)
- This means: an unmanaged-device flag alone is almost never the real signal.
  The signal is whether THIS device has been seen for THIS user before.

RULE
- If (user, device) pair has signed in before -> DISMISS
- If device is first-seen for that user -> ESCALATE, do not auto-dismiss
- If device name is missing/unnamed -> treat as first-seen, ESCALATE
  (an unnamed device cannot be matched against history, so it can't be
  confirmed known — this is a "low confidence" case by definition)
- If a device ID is known, but known for a DIFFERENT user than the one
  signing in now -> this is NOT a "seen before" match. A device being
  known is not the same as a device being known FOR THIS USER. Treat
  cross-user device reuse as its own case, route to ESCALATE / low
  confidence, never auto-dismiss on device recognition alone.
